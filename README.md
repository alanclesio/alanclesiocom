# alanclesio.com

Personal portfolio site — a single-page, zsh terminal–themed page that displays my
name and skills as a Software Developer.

## Overview

- Self-contained `index.html` (no build step, no dependencies)
- Animated terminal "boot" sequence
- Interactive shell: type `help`, `whoami`, `skills`, `about`, `contact`, `social`, `clear`
- Catppuccin Mocha color theme, JetBrains Mono typeface

## Run locally

Open `index.html` in any browser, or serve it:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```
